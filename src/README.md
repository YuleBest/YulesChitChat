## 岁岁年年

**于乐**（Yule）这个名字没有什么特殊含义，大概是中学时期取的网名。非要说的话，大概是「关于你的快乐」的意思吧。

**于乐的碎碎念**则是我对于生活的态度，我认为生活就是由无数个转瞬即逝的机会，以及无数次碎碎念构成的。

所以，感谢你愿意听我的碎碎念，也希望我能陪你岁岁年年 ~
