Markdown 支持表格语法。Markdown 的表格是比较难看的，你通常需要使用 Typora 这类可视化工具进行编辑。

## 语法

表格由表头和内容构成。

表格的列与列之间使用 `|` 隔开，首尾都添加一个 `|`。如 `| TEXT | TEXT | TEXT |`。

### 表头

表头是表格的第一行以及第二行。要使用表格，至少需要创建一个表头，如果没有完整的表头，Markdown 不会渲染表格。

表头的语法是：

- 在第一行设置每一列的名称
- 在第二行定义该列的对齐方式，`-` 号的数量没有规定，但建议至少 3 个：
  - `:----` 表示左对齐
  - `:---:` 表示居中对齐
  - `----:` 表示居右对齐

::: tabs

@tab Markdown

```md
| 列 1 | 列 2 | 列 3 |
| :--- | :--: | ---: |
```

@tab 渲染效果

| 列 1 | 列 2 | 列 3 |
| ---- | ---- | ---- |

:::

### 表内容

从第三列开始，你可以设置表的内容。表内容支持其他 Markdown 格式，但不支持引言、代码块。

如果想在单元格内换行，需要使用 HTML 标签 `<br>`。

::: tabs

@tab Markdown

```md
| 列 1            |   列 2   |           列 3 |
| :-------------- | :------: | -------------: |
| **粗体**        |  _斜体_  | 行 1 <br> 行 2 |
| [链接](./table) | ==高亮== |     `行内代码` |
```

@tab 渲染效果

| 列 1            |   列 2   |           列 3 |
| :-------------- | :------: | -------------: |
| **粗体**        |  _斜体_  | 行 1 <br> 行 2 |
| [链接](./table) | ==高亮== |     `行内代码` |

:::
