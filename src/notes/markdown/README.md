Markdown 是一种轻量级标记语言，由约翰·格鲁伯（John Gruber）和亚伦·斯沃茨（Aaron Swartz）于 2004 年创建。它旨在让人们使用易读易写的纯文本格式编写文档。Markdown 的语法简洁直观，学习成本低，广泛应用于撰写说明文档、技术博客、电子书、论坛帖子等。

Markdown 的语法符号均是由标点符号组成，比如 `#`、`*`、`-` 等，会让你有种「就该这样子」的感觉。

本教程将完整介绍 Markdown，帮助你快速上手编写 Markdown 文档。
